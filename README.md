## Fitur yang Dibuat (so far)
- Kernel Entrypoint & GDT/IDT: Inisialisasi dasar kernel x86 32-bit, penanganan interupsi, dan port I/O.
- Driver Framebuffer & Keyboard: Output tampilan teks/grafis serta masukan papan ketik.
- File System (EXT2): Pembacaan dan pengelolaan direktori/file pada sistem berkas EXT2.
- Virtual Memory & Paging: Pengelolaan memori tingkat lanjut dan pemisahan mode Kernel/User.
- Process & Scheduler: Pengelolaan proses dan penjadualan (multi-tasking).
